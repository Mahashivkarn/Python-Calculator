# 🧮 Python Calculator

A simple command-line calculator built using Python's `match-case` statement.

## Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ❌ Invalid operator handling
- 🚫 Division by zero handling

## Technologies Used

- Python 3.10+
- Match-Case

## Concepts Learned

- Variables
- User Input
- Conditional Statements
- Match-Case
- Error Handling

## How to Run

```bash
python calculator.py
```

## Example

```
Enter first number: 15
Enter second number: 5
Choose an operator (+, -, *, /): *

Multiplication: 75
```
